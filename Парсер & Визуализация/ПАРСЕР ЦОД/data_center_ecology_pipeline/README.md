# Сборщик данных о дата-центрах

Проект собирает открытые сведения о дата-центрах и извлекает экологические показатели из локальных PDF-отчётов. Основные метрики: PUE, WUE и CUE. Неизвестные значения не заменяются нулём.

## 1. Структура проекта

```text
data_center_ecology_pipeline/
├── data_center_ecology/
│   ├── sources/                 адаптеры источников
│   │   ├── atlas.py             каталог ATLAS
│   │   └── base.py              сетевой клиент и HTML-шаблон
│   ├── parsers/                 парсеры документов
│   │   └── pdf_parser.py        извлечение метрик из PDF
│   ├── config.py                пути и лимиты запросов
│   ├── main.py                  командная строка
│   ├── models.py                схемы записей
│   ├── normalization.py         числа, страны и годы
│   ├── validation.py            проверки качества
│   └── storage.py               сохранение CSV и русских копий
├── data/
│   ├── raw/                     исходные PDF и выгрузки
│   ├── normalized/              готовые CSV и Excel
│   └── logs/                    журнал работы
├── tests/                       локальные автоматические тесты
├── README.md                    эта инструкция
├── requirements.txt             зависимости
└── pytest.ini                   настройки pytest
```

## 2. Установка

Нужен Python 3.11 или новее.

```powershell
cd "ПРОЕКТ\Парсер & Визуализация\ПАРСЕР ЦОД\data_center_ecology_pipeline"
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Если PowerShell запрещает активацию окружения, выполните один раз:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

Проверка установки:

```powershell
python --version
python -m pytest -q
```

## 3. Основной рабочий процесс

### Шаг 1. Получить каталог дата-центров

```powershell
python -m data_center_ecology.main atlas
```

Для пробного запуска:

```powershell
python -m data_center_ecology.main atlas --limit 100
```

Адаптер обращается к открытому CSV ATLAS и сохраняет название объекта, компанию, страну, регион, город и адрес. Он не пытается обходить ограничения сайта и не выдумывает координаты.

### Шаг 2. Обработать PDF-отчёт

Положите исходный PDF в `data/raw/` или укажите путь к нему:

```powershell
python -m data_center_ecology.main pdf `
  "..\..\..\Презентации & Таблицы\Экологические последствия работы ЦОД.pdf" `
  --source-name "Экологический отчёт" `
  --metric-scope unknown
```

Если отчёт явно относится ко всей компании:

```powershell
python -m data_center_ecology.main pdf `
  "data\raw\company_report.pdf" `
  --source-name "Годовой ESG-отчёт" `
  --source-url "https://официальная-ссылка-на-отчёт" `
  --year 2024 `
  --metric-scope company
```

Допустимые значения `--metric-scope`:

```text
facility  конкретный дата-центр
company   компания целиком
region    регион
fleet     группа объектов
industry  отрасль
unknown   область не установлена
```

Не выбирайте `facility`, если PDF сообщает только среднее значение компании или группы объектов.

### Шаг 3. Построить сводку

```powershell
python -m data_center_ecology.main summary
```

Сводка не смешивает показатели разных лет, областей применения или методик. При конфликте значение остаётся пустым, а причина записывается в примечание.

### Шаг 4. Обновить данные на сайте

После загрузки каталога или обработки нового PDF экспортируйте нормализованные данные в существующий сайт:

```powershell
python -m data_center_ecology.main export-site
```

Если сайт находится в соседней папке репозитория, перед экспортом можно явно указать его путь:

```powershell
$env:DCE_SITE_DIR = (Resolve-Path "..\..\..\Сайт & Инструменты\САЙТ").Path
python -m data_center_ecology.main export-site
```

Команда создаёт `SITE # SOURCE/site-data.js`. Сайт использует этот файл в разделе `Данные`, где доступны поиск, фильтрация, постраничный просмотр и ссылки на источники. Повторный экспорт обновляет только выгрузку для интерфейса и не изменяет исходные CSV.

Перед публикацией результатов выполните самопроверку:

```powershell
python -m data_center_ecology.main validate
python -m data_center_ecology.main validate --strict
```

Команда `validate` ничего не исправляет: она показывает предупреждения и ошибки для сохранённых CSV. Флаг `--strict` возвращает код завершения `1`, если найдены ошибки схемы или значений; это удобно для CI и проверки перед публикацией.

Если нужно отдельно проверить и очистить значения стран в сохранённых CSV:

```powershell
python -m data_center_ecology.main sanitize
```

Неподтверждённые значения удаляются из пользовательского поля `Country`, а исходная строка сохраняется в `Notes` для аудита.

## 4. Файлы результата

Папка `data/normalized/` содержит технические CSV:

```text
datacenters.csv                    справочник дата-центров
metrics_history.csv                история метрик по годам
sources.csv                        реестр источников
datacenters_history_metrics.csv    сводка PUE/WUE/CUE
```

Русские CSV предназначены для чтения человеком и Excel:

```text
дата_центры.csv
метрики_история.csv
источники.csv
дата_центры_сводка.csv
```

Для просмотра используйте компактный Excel-файл:

```text
дата_центры_читаемый.xlsx
```

В нём есть только нужные для работы листы `Инструкция`, `Дата-центры` и `Метрики`. Лист `Сводка` не включён: текущие показатели из PDF не привязаны однозначно к конкретным ЦОД, поэтому сводка была пустой и могла вводить в заблуждение. Технические файлы `datacenters_history_metrics.csv` и `дата_центры_сводка.csv` сохранены для будущего использования.

В книге включены фильтры, закрепление заголовков, перенос длинного текста, чередование строк и границы таблиц. В листе `Дата-центры` символ `—` означает, что значение не опубликовано в источнике. В исходных CSV такие значения остаются пустыми.

В листе `Метрики` добавлена колонка `Что это значит`, а также понятные подписи охвата, типа значения и статуса проверки. Числовое значение в колонке `Значение` не следует считать показателем отдельного ЦОД, если в колонке `К чему относится` указана компания, регион или группа объектов.

## 5. Что означает пустое поле

### Широта и долгота

Используемый CSV ATLAS содержит адрес, но не содержит координаты для этих записей. Координаты нельзя подставлять по центру города, если это не отмечено как отдельная оценка. Для GIS нужен отдельный подтверждённый источник или разрешённое геокодирование.

### Статус

Источник не публикует для этих строк статус `работает`, `строится` или `закрыт`. Статус не определяется по названию компании, адресу или дате.

### Регион

Для некоторых стран и записей поле региона отсутствует в источнике. Это не означает, что регион неизвестен в реальном мире; он просто не опубликован в данной строке.

### Метрики

Пустой PUE, WUE или CUE означает, что показатель не найден или не подтверждён. Ноль означает реальное опубликованное значение ноль и не используется как замена пропуску.

## 6. Как проверять PDF-результаты

После запуска откройте `метрики_история.csv` или лист `Метрики`.

Для каждой строки проверьте:

1. название метрики;
2. год и отчётный период;
3. единицу измерения;
4. охват показателя;
5. страницу PDF;
6. фрагмент исходного текста;
7. статус `нужна проверка`.

Парсер не является универсальным распознавателем таблиц. Если в одной строке несколько чисел или годов, он оставляет значение пустым и сохраняет строку как кандидата для ручной проверки.

Сканированные PDF без текстового слоя потребуют отдельного OCR-процесса. OCR в проект не включён автоматически.

## 7. Повторный запуск

Повторный запуск не удаляет историю. Записи объединяются по стабильным идентификаторам и источникам. Если источник временно недоступен, старые данные не стираются.

Рекомендуемый порядок обновления:

```powershell
python -m data_center_ecology.main atlas
python -m data_center_ecology.main pdf "data\raw\новый_отчёт.pdf" --source-name "Новый отчёт"
python -m data_center_ecology.main summary
```

## 8. Тесты

```powershell
python -m pytest -q
```

Тесты не обращаются к интернету. Они проверяют нормализацию чисел, PDF-кандидаты, повреждённые PDF, дубликаты, схему CSV, сетевые ошибки и разделение корпоративных и объектных показателей.

## 9. Типичные ошибки

`ModuleNotFoundError` — активируйте `.venv` и выполните `python -m pip install -r requirements.txt`.

`HTTP 403` или `HTTP 429` — источник ограничил доступ. Не обходите ограничение; подождите, уменьшите частоту запросов или используйте разрешённую выгрузку.

`Файл не найден` — проверьте путь к PDF. В PowerShell путь с пробелами заключайте в кавычки.

`нужна проверка` — это не сбой. Откройте страницу PDF и проверьте контекст, год и единицу вручную.

Пустые координаты — ожидаемый результат для текущего CSV. Они не должны заменяться нулями или случайными координатами.

## 10. Источник каталога

Проект использует [ATLAS / Global Data Center Map](https://data-center-map.com/) и его опубликованный [репозиторий с CSV](https://github.com/Ringmast4r/Global-Data-Center-Map). Для использования требуется атрибуция автора набора данных. Источник является снимком, а не гарантированно актуальной базой в реальном времени.
